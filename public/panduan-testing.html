Tahapan Uji Coba Rinci & Target Pemeriksaan Bug

1

Uji Coba Master Data & Submenu Settings

Memeriksa struktur sidebar, submenu settings, dan tipe pencatatan Part Number.

Menu: Logistic -> Settings
Langkah Pengujian:
  1. Buka menu Logistic di sidebar kiri, perhatikan ada menu collapsible Settings.
  2. Buka Settings, pastikan terdapat 3 menu: Part Number, Rack, dan Item Types.
  3. Klik menu Part Number -> Klik tombol Add Part Number.
  4. Perhatikan pilihan Radio: Serialized (SN & MAC ID) vs Non-Serialized (Quantity / Non-SN).
  5. Klik tombol Import -> Pilih file sample-import-part-number.xlsx -> Upload.
Yang Harus Dipastikan (Target Bug):
  • Import berhasil memasukkan 10 Part Number baru.
  • Badge penanda di tabel Part Number muncul sesuai: Serialized (SN) warna biru, dan Non-Serial (Qty) warna kuning.
  • Submenu Settings tetap terbuka (tidak menutup sendiri) saat user berada di halaman Part Number / Rack / Item Types.
2

Uji Coba Pengadaan (PO) & Konfirmasi Tombol Approve

Membuat Purchase Order, verifikasi letak tombol Approve di menu PO, lalu penerimaan barang fisik.

Menu: Purchasing -> Purchase Order
Langkah Pengujian:
  1. Buka menu Purchase Order -> Klik Create PO.
  2. Pilih Supplier, masukkan Nomor PO (misal: PO-TEST-001), tambahkan item Part Number (misal: CCR2216-1G-12XS-2XQ Qty 2). Simpan PO.
  3. Status PO pertama kali adalah Draft.
  4. Makesure Tombol Approve: Buka detail PO tersebut (klik nomor PO). Di bagian atas ada panel konfirmasi: Tombol hijau Approve dan tombol merah Reject.
  5. Klik tombol Approve (pastikan user punya hak purchasing.approve).
  6. Setelah di-approve, buka kembali PO tersebut: Panel Receive Items (Penerimaan Barang) sekarang telah terbuka!
  7. Masukkan Serial Number unit (misal: CCR2216-SN-001 dan CCR2216-SN-002), lalu klik Receive Items.
Yang Harus Dipastikan (Target Bug):
  • Tombol Approve tetap berada di halaman detail PO di menu Purchasing.
  • Penerimaan barang fisik tidak bisa dilakukan sebelum PO disetujui (status approved/ordered).
  • Unit fisik yang diterima otomatis masuk ke daftar Inventories dengan status Available dan berelasi ke nomor PO tersebut.
3

Uji Coba Add Item (Toggle SN vs Qty & Validasi Serialized)

Mencoba input barang langsung ke gudang dan memvalidasi pencegahan SN kosong.

Menu: Logistic -> Inventories -> Add Item
Langkah Pengujian:
  1. Buka menu Inventories -> Klik Add Item.
  2. Pilih Part Number yang bertipe Serialized (misal: RB5009UG+S+IN). Form akan otomatis berada di mode Serialized (Scan SN).
  3. Uji Validasi Penolakan: Kosongkan kotak Serial Number, lalu klik Save Item.
  4. Sistem harus menolak dan memunculkan notifikasi bahwa barang serialized wajib mengisi SN.
  5. Scan / masukkan SN yang valid (misal: RB5009-TEST-999), lalu simpan.
  6. Ulangi dengan memilih Part Number non-serial (misal: UTP-CAT6-BELDEN-305M). Form otomatis berganti ke mode Non-Serialized (Quantity). Masukkan Qty 5 roll, lalu simpan.
Yang Harus Dipastikan (Target Bug):
  • Barang Serialized sama sekali tidak boleh bisa tersimpan tanpa Serial Number.
  • Jika tombol toggle di klik manual (beralih dari Serialized ke Qty), inputan barcode scan tersembunyi dan inputan kuantitas angka muncul secara mulus.
4

Uji Coba Filter & Pencarian Unit (Detail Part Number)

Mengecek bilah filter lengkap di halaman part dan kolom dinamis SN vs Qty.

Menu: Logistic -> Inventories -> Klik Salah Satu Part Number
Langkah Pengujian:
  1. Buka menu Inventories -> Klik baris Part Number CCR2216-1G-12XS-2XQ.
  2. Perhatikan bilah filter di atas tabel: ada input SN, Part Number, Item Name, serta dropdown Condition, Status, dan Warehouse.
  3. Coba ketik potongan SN (misal: 001) dan klik Apply Filter. Tabel harus menyaring unit yang cocok.
  4. Kembali ke Inventories, klik Part Number non-serial (misal: UTP-CAT6-BELDEN-305M).
  5. Perhatikan header tabel: Kolom SN / MAC ID hilang secara otomatis dan digantikan oleh Qty / Satuan!
  6. Coba ketik kata kunci di kotak search sidebar kiri ("Search SN, PN, item..."): Sistem langsung membawa Anda ke halaman unit search dengan hasil yang relevan.
Yang Harus Dipastikan (Target Bug):
  • Reset filter mengembalikan tabel ke daftar utuh.
  • Pencarian global di sidebar tidak menyebabkan error atau 404.
  • Tidak ada header SN yang muncul pada barang yang bertipe non-serial (Qty).
5

Uji Coba Work Order & Delivery Order (Fix Bug Stok 0)

Memastikan stok Available terbaca di WO, alokasi unit fisik, dan pengiriman DO.

Menu: Sales -> Work Order & Logistic -> Delivery Order
Langkah Pengujian:
  1. Buka menu Sales -> Work Order -> Klik Create Work Order.
  2. Pilih Customer, isi subject, lalu tambahkan baris item.
  3. Pada dropdown Part Number, pilih item yang tadi sudah dimasukkan ke gudang (misal: CCR2216-1G-12XS-2XQ).
  4. Periksa Kuantitas Stok: Pastikan stok yang tertulis di samping Part Number menampilkan jumlah stok yang sebenarnya (misal: (2 Available), BUKAN 0!).
  5. Simpan WO -> Klik tombol Accept Work Order (status menjadi accepted).
  6. Sekarang pindah ke menu Logistic -> Delivery Order (perhatikan posisinya sudah berada di bawah Logistic!).
  7. Klik Create Delivery Order from WO -> Pilih WO yang baru saja di-accept.
  8. Sistem membuat DO dengan status picking dan mengunci unit fisik dari gudang.
  9. Lakukan scan / verifikasi SN yang dikirim, lalu klik tombol Ship Delivery Order.
Yang Harus Dipastikan (Target Bug):
  • Stok barang berstatus Available terbaca akurat di form WO (tidak lagi 0).
  • Delivery Order berada di grup menu Logistic (bukan Sales).
  • Setelah DO dikirim (status delivered), unit fisik di Inventories gudang berubah status menjadi Sold Out dan tanggal Stuff Out terisi.
6

Uji Coba Dark Mode UI & Dropdown Select2

Memeriksa keterbacaan teks dropdown Select2 dan warna kontras saat tema gelap aktif.

Aksi: Toggle Dark Mode di Topbar
Langkah Pengujian:
  1. Klik ikon Bulan (Moon) di header atas sebelah kanan untuk mengaktifkan Dark Mode.
  2. Buka halaman Inventories -> Add Item.
  3. Klik dropdown Part Number (Select2 dropdown).
  4. Ketik kata kunci di dalam kolom pencarian Select2.
  5. Lihat warna daftar opsi yang muncul.
Yang Harus Dipastikan (Target Bug):
  • Latar belakang dropdown Select2 berwarna gelap (`#1E293B`), TIDAK putih lagi.
  • Teks pilihan berwarna putih terang (`#F8FAFC`), dapat dibaca dengan sangat jelas.
  • Saat opsi disorot (hover), latar belakang berubah menjadi biru brand (`#0066A0`) dengan teks putih bersih.
  • Tidak ada teks putih yang bertumpuk di atas latar belakang putih.
